# Pupu MVP 实施计划

**Overall Progress:** `100%`

## TLDR

Pupu 是一款心理+生理健康管理 App，MVP 包含：排便记录（含图表、报告、导出）、健康管理（GAD-2/PHQ-2 问卷、内置引导内容、基于记录的倾向提示与科普）、私人空间。技术栈：Flutter + Supabase，数据本地存储 + 云端备份。

---

## Critical Decisions

- **Flutter** — 双端复用、创意 UI 表现力强；预算有限时优先 iOS
- **Supabase** — 云端备份、Auth、成本可控
- **本地 + 云端双存储** — 离线可用，云端备份可恢复
- **GAD-2 + PHQ-2** — MVP 心理问卷，简短易用
- **8 色预设** — 淡粉橙、暖米色、浅米白、白瓷色、深暖褐、柔和橙、焦糖色、暖棕色
- **倾向提示非诊断** — 健康建议基于记录做倾向性提示，明确「非医疗建议」
