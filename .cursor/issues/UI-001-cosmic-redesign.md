# UI-001: 宇宙主题 UI 彻底重构

**Type:** Feature | **Priority:** High | **Effort:** Large

---

## TL;DR

取消底部 Tab 导航，以「星空主页面 + Pupu 宠物」为核心入口。左下角小光点轻点进入记录档案，长按 Pupu 缩放进入私人空间（银河深处），点击「和我一起流动」进入排便计时流程。采用深夜宇宙主题、柔和动效、玻璃卡片设计。

---

## Current vs Expected

| 维度 | 当前 | 预期 |
|------|------|------|
| 导航 | 底部 3 Tab（记录/健康/私人空间） | 无底部栏，主页面为核心 |
| 主页面 | 无，直接进记录列表 | 星空背景 + Pupu 宠物 + 悬浮文案 |
| 入口 | Tab 切换 | 主页面 → 左下光点档案 / 长按 Pupu 私人空间 / 点击「和我一起流动」计时 |
| 主题 | 暖色系 | 深夜宇宙（深蓝渐变、微粒、呼吸感） |
| 动效 | 无 | 呼吸、微粒漂浮、流星、水面波纹、过渡 1.5s |

---

## 1. 主页面（星空）

- **背景**：夜空星幕，渐变极缓慢流动，星空微粒缓慢漂浮，星点偶尔闪烁，偶尔流星
- **中心**：Q 弹可爱大便形象（Pupu 宠物），轻微 scale 呼吸（3–4 秒周期）；**首版用占位图**
- **上方**：随机文案「今天的宇宙，很安静」「慢一点，也没关系」
- **下方**：轻微闪烁透明字「和我一起流动」→ 点击进入计时页面

---

## 2. 计时页面

- **计时含义**：排便时长，用户手动点击开始/结束
- **背景**：深蓝渐变，半透明水面层，柔和光晕，缓慢波纹
- **动效**：水面轻微、缓慢波动，呼吸圈扩散
- **进入**：星空渐暗，水面渐显，声音淡入（1.5s）
- **计时中**：可播放白噪音/轻音乐/呼吸节奏；水面上偶尔浮现温柔字句并消散
  - 例：「排便也是一种释放」「这一刻，只属于你」「放轻松，给身体一点时间」
- **结束**：结束语（如「谢谢自己的身体」「今天的你也辛苦了」）→ **嵌入式简化布里斯托表单**（本次排便形态等）→ 保存记录 → 底部闪烁「回返星空」→ 点击返回主页面（水面柔光 → 光粒 → 下沉淡入星空）

---

## 3. 记录档案页（宇宙档案）

- **入口**：主页面左下角**隐蔽小光点**，轻点 → 档案浮现（非滑动）
- **UI**：半透明玻璃层（轻模糊），背景仍为宇宙；**关闭**：点击关闭按钮 或 下滑
- **内容**：a) 排便记录（时间、形态、颜色、时长、备注、图表）b) 健康建议 c) 周/月/年报告 d) 心理问卷（本版沿用 GAD-2 + PHQ-2，排便问卷未来计划）
- **健康建议逻辑**：用户**初次记录前**展示独立【健康建议卡片】（静态文案）；**记录后**基于最近记录自动生成相关建议
- **四色书签**：
  - 蓝：排便记录
  - 灰绿：健康建议
  - 烟紫：报告分析
  - 灰蓝：心理问卷
- **图表**：线条柔和、无硬边、低饱和

---

## 4. 私人空间（银河深处）

- **入口**：主页面**长按 Pupu 中心** → 画面**缩放进入**银河深处（不同空间层级）
- **内容**：文字记录、**文件上传**（附件存 Supabase Storage）；占位符：「你可以对宇宙说话」「今晚的星光为你闪烁」
- **UI**：银河、深紫渐变、微粒、极慢星云漂浮
- **数据**：`PrivateEntry` 需增加附件字段，存储路径或 Supabase 引用

---

## 5. 主题与色板

- **模式**：昼夜双模式（本版仅做深夜宇宙）
- **夜间色板**：
  - 深蓝 `#0B1026`
  - 星蓝 `#1B2A49`
  - 水光蓝 `#4C8EFF`
  - 柔光白 `#E6F0FF`
- **白昼色板**（预留）：奶油白 `#F7F4EF`、柔阳金 `#FFD89C`、浅天空蓝 `#BFD8FF`
- **动效节奏**：呼吸 3–4s，页面过渡 1.5s，**禁止弹跳曲线**

## Risks & Notes

- **性能**：首版采用简化动效（40–60 星、无流星、简化波纹），见 TECH-STACK 4.1
- **Pupu 形象**：首版用占位图
- **音频**：audioplayers，仅本地播放 + 淡入淡出
- **附件**：私人空间需 Supabase Storage + RLS，未配置时附件功能降级或提示
- **Provider 分层**：初期设计好 `lib/providers/` 结构，见 TECH-STACK 2.1
